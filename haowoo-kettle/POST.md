## บทพากย์ (ตามลำดับ) — เสียงหมูน่ารัก แหลมแต่นุ่มสบายหู + เสียงอู๊ดเบา ๆ แทรกช่วงเว้นวรรค
1. อู๊ด! หยุดเลื่อนก่อน! ใครยังต้มน้ำร้อนจัดไปชงกาแฟ ฟังอู๊ดอี๊ดทางนี้
2. กาต้มน้ำคอห่าน ฮาววู สีครีม ด้ามลายไม้ สไตล์วินเทจ ตั้งไว้มุมกาแฟ คือดูแพงมาก
3. จุดเด็ดคือ ปรับอุณหภูมิได้ ตั้งแต่สี่สิบ ถึงหนึ่งร้อยองศา
4. กาแฟดริป เก้าสิบสององศา ชาเขียว แปดสิบ นมลูก สี่สิบห้า เลือกได้เป๊ะ ดูบนจอแอลอีดีได้เลย
5. ไฟพันสองร้อยวัตต์ เดือดไว จุศูนย์จุดเก้าลิตร ข้างในสแตนเลสสามศูนย์สี่ ฟู้ดเกรด
6. มีโหมดรักษาอุณหภูมิ แล้วยังตั้งเวลาต้มล่วงหน้าได้ ตื่นมาก็ชงได้ทันที
7. ปลอดภัยสองชั้น น้ำแห้งตัดไฟ ยกออกจากฐานตัดไฟ ประกันสิบสองเดือน
8. ใช้เองก็ดี ให้เป็นของขวัญขึ้นบ้านใหม่ก็เริ่ด อู๊ดอี๊ดเอาจริง กดตะกร้าด้านล่างเลย อู๊ด!

## สร้างใหม่
```bash
pip install edge-tts
python3 tts.py          # เสียงพากย์ + แต่งเสียงหมู
python3 build_audio.py  # มิกซ์เสียง + เสียงอู๊ด + เพลง
node render.js
```
