## บทพากย์ (ตามลำดับ) — แอนิเมชันหมูชงกาแฟ/ชา/นม + เสียงหมูแหลมนุ่ม
1. อู๊ด! หยุดเลื่อนก่อน! วันนี้หมูจะชงเครื่องดื่มให้ดู ด้วยกาคอห่าน ฮาววู
2. ดีไซน์วินเทจ สีครีม ด้ามลายไม้ ปรับอุณหภูมิได้ ตั้งแต่สี่สิบ ถึงหนึ่งร้อยองศา
3. กาแฟดริป ตั้งเก้าสิบสององศา คอห่านเทน้ำได้นิ่ง กลิ่นหอมออกมาเต็มๆ
4. ชาเขียวญี่ปุ่น ใช้แปดสิบองศา ชาไม่ขม หอมละมุน
5. ชงนมให้ลูก สี่สิบห้าองศา อุ่นกำลังดี
6. ไฟพันสองร้อยวัตต์ เดือดไว จุศูนย์จุดเก้าลิตร ข้างในสแตนเลสสามศูนย์สี่ ฟู้ดเกรด
7. รักษาอุณหภูมิได้ ตั้งเวลาต้มล่วงหน้าได้ ตื่นมาก็ชงได้ทันที
8. ยกออกจากฐานตัดไฟ น้ำแห้งตัดไฟ ประกันสิบสองเดือน
9. ใช้เองก็ดี ให้เป็นของขวัญก็เริ่ด กดตะกร้าด้านล่างเลย อู๊ด!

## สร้างใหม่
```bash
pip install edge-tts
python3 tts.py          # เสียงพากย์ + แต่งเสียงหมู
python3 build_audio.py  # มิกซ์เสียง + เสียงอู๊ด + เพลง
node render.js
```
